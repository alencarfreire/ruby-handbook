# Ruby/Rails Interview Handbook

> Guia para entrevista de Ruby/Rails: exemplos reais, exercícios práticos e respostas prontas.

## Sobre o livro

Este handbook tem:

- Temas do Junior ao Senior
- **TL;DR** para revisar rápido
- **Exemplos práticos** com código que roda
- **Exercícios práticos** para fixar
- **Respostas prontas** para entrevista

## Para quem é

- **Junior** — fundamentos de Ruby e Rails
- **Middle** — aprofundar e se preparar para entrevista
- **Senior** — organizar o que você já sabe e revisar antes da entrevista
- **Entrevistadores** — base de perguntas

## Estrutura

### Nível 1: Fundamentos de Ruby (Junior)
- Ruby Basics — tipos, variáveis, blocos, Enumerable
- OOP em Ruby — classes, modules, mixins, `self`
- Ruby avançado — gem, Bundler, metaprogramação

### Nível 2: Rails (Middle)
- Rails Basics — rotas, MVC, concern, boot
- Rails avançado — Active Record, jobs, Turbo
- SQL & Databases — queries, transações, N+1

### Nível 3: Arquitetura & Testes
- RSpec, FactoryBot, TDD
- Service Object, Form Object, Policy
- Segurança — XSS, CSRF, autenticação

### Nível 4: Infra
- Docker, Sidekiq, Redis, cache
- Performance, Action Cable

## Como usar

**Para estudar:** leia na ordem, do simples ao avançado. Cada tema leva ~10–15 minutos.

**Antes da entrevista:** leia **Na entrevista** em cada tema e prepare exemplos da sua experiência.

## Formato de cada tema

1. **TL;DR** — revisar rápido
2. **Conteúdo** — navegação
3. **O que é** — definição simples
4. **Como funciona** — código
5. **Na entrevista** — resposta falada
6. **Exercícios práticos**
